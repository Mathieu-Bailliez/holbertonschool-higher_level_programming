# JavaScript - DOM Manipulation

This project covers selecting and modifying HTML elements with JavaScript,
handling user events, and fetching data from APIs with the Fetch API.

## Files

| File | Description |
|------|-------------|
| `0-script.js` | Sets the `header` text color to red |
| `1-script.js` | Turns the `header` red when `#red_header` is clicked |
| `2-script.js` | Adds the `red` class to `header` on click |
| `3-script.js` | Toggles the `header` class between `red` and `green` |
| `4-script.js` | Adds a `<li>Item</li>` to `ul.my_list` on click |
| `5-script.js` | Changes the `header` text to `New Header!!!` on click |
| `6-script.js` | Fetches and displays a Star Wars character name |
| `7-script.js` | Fetches and lists all Star Wars movie titles |
| `8-script.js` | Fetches and displays "hello" in French |

## Requirements

- Chrome 57+
- Code is `semistandard` compliant
- No use of `var`
